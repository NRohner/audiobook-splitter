# Terminal App (`tui`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `cargo run -- tui` opens one full-screen terminal app that does everything the web GUI does (choose a book, set analysis options, watch the analysis, edit chapters, set tags and cover art, split), and `edit`/`run` use the same full-screen chapter editor.

**Architecture:** A `ratatui` app in `src/cli/tui/`. Each screen is a plain struct with `handle_key(key)` and `render(frame)` (no terminal I/O), so tests drive them with synthetic keys and `TestBackend`. A thin loop owns the terminal. Analysis and splitting run on a worker thread and stream the existing `pipeline::Event`s over an `mpsc` channel into progress screens. The chapter editor (slice 1) is reused unchanged by the app (slice 2) and gets a file browser for the cover image (slice 3).

**Tech Stack:** Rust 2024, `ratatui = "0.30"` (the only new dependency; it re-exports `crossterm` as `ratatui::crossterm`), FFmpeg/FFprobe as today.

Spec: `docs/superpowers/specs/2026-11-16-tui-app-design.md` (detailed editor behaviour: `docs/superpowers/specs/2026-11-14-tui-editor-design.md`).

This one plan covers all three slices of the spec, in order:
- **Slice 1 (Tasks 1-7):** foundation and chapter editor, used by `edit` and `run`.
- **Slice 2 (Tasks 8-12):** file browser, Setup, progress screens, the `tui` command and its screen flow.
- **Slice 3 (Tasks 13-15):** cover-image browser, help popups and small-terminal checks on every screen, docs and final verification. (Back navigation from the editor to Setup is built into slices 1-2, where it is cheaper than retrofitting.)

Each slice ends in a working, committed state; every task ends with `cargo test` green.

## Global Constraints

- The only new dependency is `ratatui = "0.30"`. No other crates. The file browser and text input are hand-written on `std::fs`.
- `edit` and `run` open the full-screen editor by default; the existing prompt menu is used instead with `--simple`, when stdin or stdout is not a TTY, when `TERM` is unset/empty/`dumb` (on Windows an unset `TERM` counts as fine), when the terminal is smaller than 60 columns by 15 rows, or when terminal setup fails (print `Full-screen editor unavailable (<reason>); using the plain menu.`).
- `tui` has no menu fallback: on an unsuitable terminal it prints why and suggests `run` or the individual commands, and exits with an error.
- The terminal is always restored: `ratatui::try_init()` (which installs a panic hook) in `TerminalGuard::new`, and `ratatui::restore()` in its `Drop`. Ctrl-C is handled as a key.
- Handle only `KeyEventKind::Press` key events (Windows also sends releases).
- Screens do no terminal I/O in `handle_key`/`render`. Long work (analysis, splitting) runs on a worker thread and reports through `pipeline::Event`; the loop redraws at most every ~100 ms.
- Not included: mouse support, in-terminal audio playback, cancelling a running job, a rescan key, themes, multi-select.
- No emojis anywhere in the UI; plain ASCII text and ratatui borders only.
- Tests first; each task ends with `cargo test` passing and a commit. Match surrounding style (`//` comments above items). Do not run `cargo fmt` over existing files.
- Commit messages end with: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`. Never stage anything that is not listed in the task.

// Cuts PREVIEW_SECONDS after chapter `n` (1-based, as in the chapter list) to `out` (default
// break-N.mp3 in the current folder). Returns the file written and a "Wrote ..." line.
pub fn write_clip(plan: &Plan, n: usize, out: Option<PathBuf>) -> Result<(PathBuf, String), String> {
    let b = n
        .checked_sub(1)
        .and_then(|i| plan.findings.breaks.get(i))
        .ok_or(format!("There is no chapter {} in this plan.", n))?;
    let mp3 = preview_clip(&plan.files[b.file].path, b.at, PREVIEW_SECONDS)?;
    let out = out.unwrap_or_else(|| PathBuf::from(format!("break-{}.mp3", n)));
    std::fs::write(&out, mp3).map_err(|e| format!("Failed to write '{}': {}", out.display(), e))?;
    let line = format!("Wrote {} s from \"{}\" ({}) to {}.", PREVIEW_SECONDS, b.title, place(plan, b.file, b.at), out.display());
    Ok((out, line))
}

pub fn run(args: Args) -> Result<(), String> {
    super::check_tools()?;
    let plan = open_plan(&args.plan)?;
    let (out, line) = write_clip(&plan, args.n, args.out)?;
    println!("{}", line);

    // ponytail: only plays on request; detecting a local audio device isn't portable.
    if args.play {
        Command::new("ffplay")
            .args(["-nodisp", "-autoexit", "-loglevel", "quiet"])
            .arg(&out)
            .status()
            .map_err(|_| "ffplay was not found on your PATH (it ships with FFmpeg). Play the file yourself, e.g. after `scp`.".to_string())?;
    }
    Ok(())
}

// Entering and leaving the full-screen terminal safely, and deciding whether to.
use ratatui::DefaultTerminal;
use std::io::IsTerminal;

// Smaller than this and a full-screen layout stops being useful.
pub const MIN_SIZE: (u16, u16) = (60, 15);

// Whether a full-screen UI is a good idea here.
pub fn use_tui(simple: bool, term: Option<&str>, size: (u16, u16), is_tty: bool) -> bool {
    !simple && is_tty && term.is_some_and(|t| !t.is_empty() && t != "dumb") && size.0 >= MIN_SIZE.0 && size.1 >= MIN_SIZE.1
}

// `use_tui` for the real environment. Windows terminals don't set TERM, so there it counts as fine.
pub fn suitable(simple: bool) -> bool {
    let size = ratatui::crossterm::terminal::size().unwrap_or((0, 0));
    let tty = std::io::stdin().is_terminal() && std::io::stdout().is_terminal();
    let term = std::env::var("TERM").ok().or_else(|| cfg!(windows).then(|| "windows".to_string()));
    use_tui(simple, term.as_deref(), size, tty)
}

// Raw mode and the alternate screen, undone on drop. `try_init` also installs a panic hook
// that restores the terminal first, so a crash never leaves an SSH session unusable.
pub struct TerminalGuard {
    pub terminal: DefaultTerminal,
}

impl TerminalGuard {
    pub fn new() -> Result<TerminalGuard, String> {
        ratatui::try_init().map(|terminal| TerminalGuard { terminal }).map_err(|e| e.to_string())
    }
}

impl Drop for TerminalGuard {
    fn drop(&mut self) {
        ratatui::restore();
    }
}
```

// A single-line text field: characters, cursor movement and deletion. Columns are counted
// in characters, so wide (CJK) glyphs can look misaligned; that is acceptable here.
use ratatui::crossterm::event::{KeyCode, KeyEvent, KeyModifiers};

pub struct Input {
    text: Vec<char>,
    cursor: usize,
}

impl Input {
    pub fn new(initial: &str) -> Input {
        let text: Vec<char> = initial.chars().collect();
        Input { cursor: text.len(), text }
    }

    pub fn value(&self) -> String {
        self.text.iter().collect()
    }

    pub fn cursor(&self) -> usize {
        self.cursor
    }

    // Applies an editing key; false means the key isn't one (Enter, Esc, Tab, Ctrl-C, ...).
    pub fn handle_key(&mut self, key: KeyEvent) -> bool {
        let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);
        match key.code {
            KeyCode::Char('u') if ctrl => {
                self.text.clear();
                self.cursor = 0;
            }
            KeyCode::Char(c) if !ctrl => {
                self.text.insert(self.cursor, c);
                self.cursor += 1;
            }
            KeyCode::Backspace => {
                if self.cursor > 0 {
                    self.cursor -= 1;
                    self.text.remove(self.cursor);
                }
            }
            KeyCode::Delete => {
                if self.cursor < self.text.len() {
                    self.text.remove(self.cursor);
                }
            }
            KeyCode::Left => self.cursor = self.cursor.saturating_sub(1),
            KeyCode::Right => self.cursor = (self.cursor + 1).min(self.text.len()),
            KeyCode::Home => self.cursor = 0,
            KeyCode::End => self.cursor = self.text.len(),
            _ => return false,
        }
        true
    }

    // The part of the text to draw in `width` columns, scrolled so the cursor stays visible,
    // and the cursor's column within it.
    pub fn view(&self, width: usize) -> (String, usize) {
        if width == 0 {
            return (String::new(), 0);
        }
        let start = if self.cursor >= width { self.cursor + 1 - width } else { 0 };
        let end = (start + width).min(self.text.len());
        (self.text[start..end].iter().collect(), self.cursor - start)
    }
}
```

```rust
// The full-screen chapter editor: a table of chapters, what Whisper heard around the selected
// break, and single-key actions. `handle_key` and `render` (view.rs) do no terminal I/O, so
// tests drive them with synthetic keys and ratatui's TestBackend. Every change goes through
// `apply`, which snapshots first so undo/redo and refusals are uniform.
mod view;

use super::input::Input;
use super::tags::{FormOutcome, TagsForm};
use crate::cli::edit::ops::{self, Pos};
use crate::cli::preview::write_clip;
use crate::cli::time::{clock, parse_time};
use crate::cli::place;
use audiobook_splitter_rust::meta::Metadata;
use audiobook_splitter_rust::pipeline::file_name;
use audiobook_splitter_rust::plan::{Plan, PlanBreak};
use ratatui::crossterm::event::{KeyCode, KeyEvent, KeyModifiers};
use ratatui::widgets::TableState;

const PAGE: usize = 10;

pub enum Outcome {
    Continue,
    Save,
    Discard,
    Back, // Only when `allow_back` is set: return to the Setup screen.
}

#[derive(Clone)]
struct Snapshot {
    breaks: Vec<PlanBreak>,
    metadata: Metadata,
    selected: usize,
}

pub(super) enum Prompt {
    Rename(usize),
    AddTime(usize),      // file index
    AddTitle(usize, f64), // file index, seconds
    Jump,
}

pub(super) enum ListKind {
    AddFile,
    Silence { spots: Vec<Pos>, title: Option<String> }, // `title` presets the title prompt
    Missing,
}

pub(super) enum Mode {
    Normal,
    Prompt { kind: Prompt, input: Input },
    List { kind: ListKind, items: Vec<String>, selected: usize },
    Tags(TagsForm),
    ConfirmQuit,
    ConfirmBack,
    Help,
}

pub struct Editor {
    pub plan: Plan,
    pub selected: usize,
    pub allow_back: bool,
    original: (Vec<PlanBreak>, Metadata),
    undo: Vec<Snapshot>,
    redo: Vec<Snapshot>,
    pub(super) table: TableState,
    pub(super) mode: Mode,
    pub(super) status: String,
}

impl Editor {
    pub fn new(plan: Plan) -> Editor {
        let original = (plan.findings.breaks.clone(), plan.metadata.clone());
        Editor {
            plan,
            selected: 0,
            allow_back: false,
            original,
            undo: Vec::new(),
            redo: Vec::new(),
            table: TableState::default(),
            mode: Mode::Normal,
            status: String::new(),
        }
    }

    // Whether the chapters or tags differ from what the editor started with.
    pub fn changed(&self) -> bool {
        ops::changed(&self.plan, &self.original)
    }

    fn snapshot(&self) -> Snapshot {
        Snapshot { breaks: self.plan.findings.breaks.clone(), metadata: self.plan.metadata.clone(), selected: self.selected }
    }

    fn restore(&mut self, s: Snapshot) {
        self.plan.findings.breaks = s.breaks;
        self.plan.metadata = s.metadata;
        self.selected = s.selected;
    }

    fn clamp(&mut self) {
        self.selected = self.selected.min(self.plan.findings.breaks.len().saturating_sub(1));
    }

    // Runs one change; on success it becomes undoable, on refusal the plan is put back as it was.
    fn apply(&mut self, change: impl FnOnce(&mut Plan) -> Result<(), String>) -> Result<(), String> {
        let before = self.snapshot();
        match change(&mut self.plan) {
            Ok(()) => {
                self.undo.push(before);
                self.redo.clear();
                self.clamp();
                Ok(())
            }
            Err(e) => {
                self.restore(before);
                Err(e)
            }
        }
    }

    // `apply` for keys that have no prompt to stay in: a refusal goes to the status line.
    fn edit(&mut self, change: impl FnOnce(&mut Plan) -> Result<(), String>) {
        if let Err(e) = self.apply(change) {
            self.status = e;
        }
    }

    fn undo(&mut self) {
        match self.undo.pop() {
            Some(prev) => {
                let now = self.snapshot();
                self.redo.push(now);
                self.restore(prev);
                self.status = "Undone.".into();
            }
            None => self.status = "Nothing to undo.".into(),
        }
    }

    fn redo(&mut self) {
        match self.redo.pop() {
            Some(next) => {
                let now = self.snapshot();
                self.undo.push(now);
                self.restore(next);
                self.status = "Redone.".into();
            }
            None => self.status = "Nothing to redo.".into(),
        }
    }

    fn select_pos(&mut self, at: Pos) {
        if let Some(i) = self.plan.findings.breaks.iter().position(|b| ops::same((b.file, b.at), at)) {
            self.selected = i;
        }
    }

    pub fn handle_key(&mut self, key: KeyEvent) -> Outcome {
        self.status.clear();
        match std::mem::replace(&mut self.mode, Mode::Normal) {
            Mode::Normal => self.key_normal(key),
            Mode::Prompt { kind, input } => self.key_prompt(kind, input, key),
            Mode::List { kind, items, selected } => self.key_list(kind, items, selected, key),
            Mode::Tags(form) => self.key_tags(form, key),
            Mode::ConfirmQuit => self.key_confirm_quit(key),
            Mode::ConfirmBack => self.key_confirm_back(key),
            Mode::Help => Outcome::Continue, // any key closes it
        }
    }

    fn key_normal(&mut self, key: KeyEvent) -> Outcome {
        let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);
        let last = self.plan.findings.breaks.len().saturating_sub(1);
        let i = self.selected;
        match key.code {
            KeyCode::Char('c') if ctrl => return self.quit(),
            KeyCode::Char('r') if ctrl => self.redo(),
            KeyCode::Up | KeyCode::Char('k') => self.selected = self.selected.saturating_sub(1),
            KeyCode::Down | KeyCode::Char('j') => self.selected = (self.selected + 1).min(last),
            KeyCode::PageUp => self.selected = self.selected.saturating_sub(PAGE),
            KeyCode::PageDown => self.selected = (self.selected + PAGE).min(last),
            KeyCode::Home => self.selected = 0,
            KeyCode::End => self.selected = last,
            KeyCode::Enter | KeyCode::Char('r') => {
                if let Some(b) = self.plan.findings.breaks.get(i) {
                    self.mode = Mode::Prompt { kind: Prompt::Rename(i), input: Input::new(&b.title) };
                }
            }
            KeyCode::Char('[') => self.edit(|p| ops::move_break(p, i, -1)),
            KeyCode::Char(']') => self.edit(|p| ops::move_break(p, i, 1)),
            KeyCode::Char('d') => self.edit(|p| ops::remove(p, i)),
            KeyCode::Char('a') => self.open_add(),
            KeyCode::Char('n') => self.open_silences(None),
            KeyCode::Char('m') => self.open_missing(),
            KeyCode::Char('t') => self.mode = Mode::Tags(TagsForm::from_plan(&self.plan)),
            KeyCode::Char('g') => self.mode = Mode::Prompt { kind: Prompt::Jump, input: Input::new("") },
            KeyCode::Char('p') => {
                self.status = match write_clip(&self.plan, i + 1, None) {
                    Ok((_, line)) => line,
                    Err(e) => e,
                };
            }
            KeyCode::Char('u') => self.undo(),
            KeyCode::Char('s') => return Outcome::Save,
            KeyCode::Char('q') => return self.quit(),
            KeyCode::Char('b') if self.allow_back => {
                if self.changed() {
                    self.mode = Mode::ConfirmBack;
                } else {
                    return Outcome::Back;
                }
            }
            KeyCode::Char('?') => self.mode = Mode::Help,
            _ => {}
        }
        Outcome::Continue
    }

    fn quit(&mut self) -> Outcome {
        if self.changed() {
            self.mode = Mode::ConfirmQuit;
            Outcome::Continue
        } else {
            Outcome::Discard
        }
    }

    fn key_confirm_quit(&mut self, key: KeyEvent) -> Outcome {
        match key.code {
            KeyCode::Char('s') => Outcome::Save,
            KeyCode::Char('d') => Outcome::Discard,
            KeyCode::Esc => Outcome::Continue,
            _ => {
                self.mode = Mode::ConfirmQuit;
                Outcome::Continue
            }
        }
    }

    fn key_confirm_back(&mut self, key: KeyEvent) -> Outcome {
        match key.code {
            KeyCode::Char('y') => Outcome::Back,
            KeyCode::Esc | KeyCode::Char('n') => Outcome::Continue,
            _ => {
                self.mode = Mode::ConfirmBack;
                Outcome::Continue
            }
        }
    }

    fn open_add(&mut self) {
        if self.plan.files.len() > 1 {
            let items: Vec<String> = self.plan.files.iter().map(|f| file_name(&f.path)).collect();
            self.mode = Mode::List { kind: ListKind::AddFile, items, selected: 0 };
        } else {
            self.mode = Mode::Prompt { kind: Prompt::AddTime(0), input: Input::new("") };
        }
    }

    fn open_silences(&mut self, title: Option<String>) {
        let spots = ops::unused_silences(&self.plan);
        if spots.is_empty() {
            self.status = "Every silence already starts a chapter.".into();
            return;
        }
        let items = spots
            .iter()
            .map(|&(file, at)| {
                let after = self.plan.findings.silences.iter().find(|s| ops::same((s.file, s.at), (file, at))).map_or("", |s| s.after.as_str());
                let preview: String = after.chars().take(50).collect();
                format!("{}  {}", place(&self.plan, file, at), preview)
            })
            .collect();
        self.mode = Mode::List { kind: ListKind::Silence { spots, title }, items, selected: 0 };
    }

    fn open_missing(&mut self) {
        if self.plan.findings.missing.is_empty() {
            self.status = "No chapters are missing.".into();
            return;
        }
        let items = self
            .plan
            .findings
            .missing
            .iter()
            .map(|m| format!("{}. {}{}", m.chapter + 1, m.title, if m.tried { "  (a re-scan found nothing)" } else { "" }))
            .collect();
        self.mode = Mode::List { kind: ListKind::Missing, items, selected: 0 };
    }

    fn key_prompt(&mut self, kind: Prompt, mut input: Input, key: KeyEvent) -> Outcome {
        match key.code {
            KeyCode::Esc => {}
            KeyCode::Enter => match self.submit(&kind, &input.value()) {
                Ok(next) => self.mode = next,
                Err(e) => {
                    self.status = e;
                    self.mode = Mode::Prompt { kind, input };
                }
            },
            _ => {
                input.handle_key(key);
                self.mode = Mode::Prompt { kind, input };
            }
        }
        Outcome::Continue
    }

    // What happens when a prompt is accepted: the next mode, or why it was refused.
    fn submit(&mut self, kind: &Prompt, text: &str) -> Result<Mode, String> {
        match *kind {
            Prompt::Rename(i) => self.apply(|p| ops::rename(p, i, text)).map(|_| Mode::Normal),
            Prompt::AddTime(file) => {
                let at = parse_time(text)?;
                let duration = self.plan.files.get(file).map_or(0.0, |f| f.duration);
                if !(at >= 0.0 && at < duration) {
                    return Err(format!("Enter a time between 0:00:00 and {}.", clock(duration)));
                }
                Ok(Mode::Prompt { kind: Prompt::AddTitle(file, at), input: Input::new("New chapter") })
            }
            Prompt::AddTitle(file, at) => {
                self.apply(|p| ops::add(p, file, at, text))?;
                self.select_pos((file, at));
                Ok(Mode::Normal)
            }
            Prompt::Jump => self.jump(text).map(|_| Mode::Normal),
        }
    }

    // A time ("1:02:03", "0:40.5") selects the nearest chapter at or before it in the selected
    // chapter's file; a plain integer selects that chapter number.
    fn jump(&mut self, text: &str) -> Result<(), String> {
        let text = text.trim();
        let breaks = &self.plan.findings.breaks;
        if text.contains(':') || text.contains('.') {
            let at = parse_time(text)?;
            let file = breaks.get(self.selected).map_or(0, |b| b.file);
            let i = breaks
                .iter()
                .rposition(|b| b.file == file && b.at <= at)
                .ok_or("There is no chapter at or before that time in this file.")?;
            self.selected = i;
        } else {
            let n: usize = text.parse().map_err(|_| "Enter a time like 1:02:03 or a chapter number.".to_string())?;
            if n == 0 || n > breaks.len() {
                return Err(format!("There is no chapter {}.", n));
            }
            self.selected = n - 1;
        }
        Ok(())
    }

    fn key_list(&mut self, kind: ListKind, items: Vec<String>, mut selected: usize, key: KeyEvent) -> Outcome {
        let last = items.len().saturating_sub(1);
        match key.code {
            KeyCode::Esc => return Outcome::Continue,
            KeyCode::Up | KeyCode::Char('k') => selected = selected.saturating_sub(1),
            KeyCode::Down | KeyCode::Char('j') => selected = (selected + 1).min(last),
            KeyCode::Enter => {
                self.choose(kind, selected);
                return Outcome::Continue;
            }
            _ => {}
        }
        self.mode = Mode::List { kind, items, selected };
        Outcome::Continue
    }

    fn choose(&mut self, kind: ListKind, i: usize) {
        match kind {
            ListKind::AddFile => self.mode = Mode::Prompt { kind: Prompt::AddTime(i), input: Input::new("") },
            ListKind::Silence { spots, title } => {
                let (file, at) = spots[i];
                let initial = title.as_deref().unwrap_or("New chapter");
                self.mode = Mode::Prompt { kind: Prompt::AddTitle(file, at), input: Input::new(initial) };
            }
            ListKind::Missing => {
                let title = self.plan.findings.missing[i].title.clone();
                self.open_silences(Some(title));
            }
        }
    }

    fn key_tags(&mut self, mut form: TagsForm, key: KeyEvent) -> Outcome {
        match form.handle_key(key) {
            FormOutcome::Continue => self.mode = Mode::Tags(form),
            FormOutcome::Cancel => {}
            FormOutcome::Save => {
                if let Err(e) = self.apply(|p| form.apply(p)) {
                    form.error = e;
                    self.mode = Mode::Tags(form);
                }
            }
        }
        Outcome::Continue
    }
}

// Drawing the editor: the chapter table, the detail pane, the footer and the popups.
use super::*;
use ratatui::layout::{Constraint, Layout, Rect};
use ratatui::style::{Color, Modifier, Style};
use ratatui::text::{Line, Span};
use ratatui::widgets::{Block, Clear, List, ListItem, ListState, Paragraph, Row, Table, Wrap};
use ratatui::Frame;

const HELP: &[(&str, &str)] = &[
    ("Up/Down, j/k, PgUp/PgDn, Home/End", "move the selection"),
    ("Enter, r", "rename the chapter"),
    ("[  ]", "move the break to the previous / next silence"),
    ("d", "remove the chapter"),
    ("a", "add a chapter at a time"),
    ("n", "add a chapter at a silence that has none"),
    ("m", "chapters the EPUB match missed"),

    ("p", "write a preview clip of the selected break"),

    ("s", "save and continue"),
    ("q, Ctrl-c", "quit (asks if there are unsaved changes)"),
    ("b", "back to Setup (only in `tui`)"),
    ("?", "this help"),

pub(crate) fn centered(area: Rect, w: u16, h: u16) -> Rect {
    let w = w.min(area.width);
    let h = h.min(area.height);
    Rect::new(area.x + (area.width - w) / 2, area.y + (area.height - h) / 2, w, h)
}

impl Editor {
    pub fn render(&mut self, f: &mut Frame) {
        let area = f.area();
        let detail_h = match area.height {
            0..=14 => 1,
            15..=19 => 4,
            _ => 7,
        };
        let [table_area, detail_area, footer_area] =
            Layout::vertical([Constraint::Min(3), Constraint::Length(detail_h), Constraint::Length(2)]).areas(area);
        self.render_table(f, table_area);
        self.render_detail(f, detail_area);
        self.render_footer(f, footer_area);
        self.render_popup(f, area);
    }

    fn render_table(&mut self, f: &mut Frame, area: Rect) {
        let multi = self.plan.files.len() > 1;
        let where_w = if multi { 30 } else { 9 };
        let rows: Vec<Row> = self
            .plan
            .findings
            .breaks
            .iter()
            .enumerate()
            .map(|(i, b)| {
                let score = b.score.map_or("-".to_string(), |s| format!("{:.2}", s));
                let fixed = if ops::is_fixed(b) { "*" } else { "" };
                Row::new(vec![format!("{}{}", i + 1, fixed), place(&self.plan, b.file, b.at), b.title.clone(), score])
            })
            .collect();
        let title = format!(" Chapters ({}){} ", rows.len(), if self.changed() { " *" } else { "" });
        let table = Table::new(rows, [Constraint::Length(5), Constraint::Length(where_w), Constraint::Fill(1), Constraint::Length(5)])
            .header(Row::new(vec!["#", "Where", "Title", "Match"]).style(Style::new().add_modifier(Modifier::BOLD)))
            .block(Block::bordered().title(title))
            .row_highlight_style(Style::new().add_modifier(Modifier::REVERSED))
            .highlight_symbol(">");
        self.table.select(Some(self.selected));
        f.render_stateful_widget(table, area, &mut self.table);
    }

    fn render_detail(&self, f: &mut Frame, area: Rect) {
        let Some(b) = self.plan.findings.breaks.get(self.selected) else { return };
        let mut lines = vec![Line::from(vec![
            Span::styled(format!("Chapter {}: ", self.selected + 1), Style::new().add_modifier(Modifier::BOLD)),
            Span::raw(format!("{}  at {}", b.title, place(&self.plan, b.file, b.at))),
        ])];
        if ops::is_fixed(b) {
            lines.push(Line::raw("The first chapter starts the book and can't be moved or removed."));
        }
        match ops::heard(&self.plan, self.selected) {
            Some((before, after)) => {
                lines.push(Line::raw(format!("Heard before: {}", before)));
                lines.push(Line::raw(format!("Heard after:  {}", after)));
            }
            None => lines.push(Line::raw("Nothing was transcribed here (no EPUB, or the break was added by hand).")),
        }
        let silence = |dir| ops::neighbour(&self.plan, self.selected, dir).map_or("none".to_string(), |(_, at)| clock(at));
        lines.push(Line::raw(format!("Previous silence: {}   Next silence: {}", silence(-1), silence(1))));
        f.render_widget(Paragraph::new(lines).wrap(Wrap { trim: true }).block(Block::bordered().title(" Detail ")), area);
    }

    fn render_footer(&self, f: &mut Frame, area: Rect) {
        let keys = if area.width >= 100 {
            "j/k move  r rename  [ ] move break  d remove  a add  n silence  m missing  t tags  g jump  p preview  u undo  s save  q quit  ? help"
        } else if area.width >= 62 {
            "r rename  [ ] move  d remove  a add  t tags  u undo  s save  q quit  ? help"
        } else {
            "? help  s save  q quit"
        };
        let status = Span::styled(self.status.clone(), Style::new().fg(Color::Yellow));
        f.render_widget(Paragraph::new(vec![Line::raw(keys), Line::from(status)]), area);
    }

    fn render_popup(&self, f: &mut Frame, area: Rect) {
        match &self.mode {
            Mode::Normal => {}
            Mode::Prompt { kind, input } => {
                let title = match kind {
                    Prompt::Rename(_) => " New title ",
                    Prompt::AddTime(_) => " Start time (h:mm:ss) ",
                    Prompt::AddTitle(..) => " Chapter title ",
                    Prompt::Jump => " Jump to a time or a chapter number ",
                };
                let rect = centered(area, 60, 3);
                let inner_w = rect.width.saturating_sub(2) as usize;
                let (text, col) = input.view(inner_w);
                f.render_widget(Clear, rect);
                f.render_widget(Paragraph::new(text).block(Block::bordered().title(title)), rect);
                f.set_cursor_position((rect.x + 1 + col as u16, rect.y + 1));
            }
            Mode::List { kind, items, selected } => {
                let title = match kind {
                    ListKind::AddFile => " Which file? ",
                    ListKind::Silence { .. } => " Start a chapter at ",
                    ListKind::Missing => " Chapters with no break (Enter: choose a silence) ",
                };
                let rect = centered(area, 70, (items.len() as u16 + 2).min(area.height.saturating_sub(2)).max(3));
                let mut state = ListState::default();
                state.select(Some(*selected));
                let list = List::new(items.iter().map(|s| ListItem::new(s.as_str())))
                    .block(Block::bordered().title(title))
                    .highlight_style(Style::new().add_modifier(Modifier::REVERSED))
                    .highlight_symbol(">");
                f.render_widget(Clear, rect);
                f.render_stateful_widget(list, rect, &mut state);
            }
            Mode::Tags(form) => form.render(f, area),
            Mode::ConfirmQuit => confirm(f, area, " Unsaved changes ", "s save and continue    d discard    Esc keep editing"),
            Mode::ConfirmBack => confirm(f, area, " Go back? ", "Your edits to the chapters will be lost.    y go back    Esc stay"),
            Mode::Help => {
                let rect = centered(area, 78, HELP.len() as u16 + 2);
                let lines: Vec<Line> = HELP.iter().map(|(k, d)| Line::from(vec![Span::styled(format!("{:<36}", k), Style::new().add_modifier(Modifier::BOLD)), Span::raw(*d)])).collect();
                f.render_widget(Clear, rect);
                f.render_widget(Paragraph::new(lines).block(Block::bordered().title(" Keys (any key closes) ")), rect);
            }
        }
    }
}

fn confirm(f: &mut Frame, area: Rect, title: &str, text: &str) {
    let rect = centered(area, 72, 3);
    f.render_widget(Clear, rect);
    f.render_widget(Paragraph::new(text).block(Block::bordered().title(title)), rect);
}

    pub fn from_plan(plan: &Plan) -> TagsForm {

            Cover::Keep => (CoverChoice::Keep, String::new()),
            Cover::None => (CoverChoice::None, String::new()),
            Cover::File(path) => (CoverChoice::Image, path.display().to_string()),

            error: String::new(),
        }

    fn rows(&self) -> usize {
        if self.cover == CoverChoice::Image { IMAGE_ROW + 1 } else { COVER_ROW + 1 }

    fn cycle_cover(&mut self, step: i32) {
        let all = [CoverChoice::Keep, CoverChoice::None, CoverChoice::Image];
        let i = all.iter().position(|c| *c == self.cover).unwrap_or(0) as i32;
        self.cover = all[(i + step).rem_euclid(3) as usize];
    }

    pub fn handle_key(&mut self, key: KeyEvent) -> FormOutcome {
        self.error.clear();
        let rows = self.rows();
        match key.code {
            KeyCode::Esc => return FormOutcome::Cancel,
            KeyCode::Enter => return FormOutcome::Save,
            KeyCode::Tab | KeyCode::Down => self.focus = (self.focus + 1) % rows,
            KeyCode::BackTab | KeyCode::Up => self.focus = (self.focus + rows - 1) % rows,
            _ if self.focus == COVER_ROW => match key.code {
                KeyCode::Left => self.cycle_cover(-1),
                KeyCode::Right | KeyCode::Char(' ') => self.cycle_cover(1),
                _ => {}
            },
            _ if self.focus == IMAGE_ROW => {
                if !key.modifiers.contains(KeyModifiers::ALT) {
                    self.image.handle_key(key);
                }
            }
            _ => {
                self.inputs[self.focus].handle_key(key);
            }
        }
        FormOutcome::Continue
    }

    // convention, or an image path that is empty or not a readable JPEG/PNG.

use audiobook_splitter_rust::plan::Plan;
use editor::{Editor, Outcome};
use ratatui::crossterm::event::{self, Event, KeyEventKind};
use terminal::TerminalGuard;

// Runs the full-screen chapter editor on `plan`. Returns whether to save; on true `*plan`
// holds the edited plan. The terminal is restored before this returns.
pub fn edit(plan: &mut Plan, mut guard: TerminalGuard) -> Result<bool, String> {
    let mut ed = Editor::new(plan.clone());
    let outcome = loop {
        guard.terminal.draw(|f| ed.render(f)).map_err(|e| e.to_string())?;
        match event::read().map_err(|e| e.to_string())? {
            Event::Key(key) if key.kind == KeyEventKind::Press => match ed.handle_key(key) {
                Outcome::Continue | Outcome::Back => {}
                done => break done,
            },
            _ => {} // Resize and the rest: just redraw.
        }
    };
    drop(guard);
    match outcome {
        Outcome::Save => {
            *plan = ed.plan;
            Ok(true)
        }
        _ => Ok(false),
    }
}

use super::input::Input;
use audiobook_splitter_rust::user_path;
use ratatui::crossterm::event::{KeyCode, KeyEvent, KeyModifiers};
use ratatui::layout::{Constraint, Layout, Rect};

#[derive(Clone, Copy)]
pub enum Pick {
    Folder,
    File(&'static [&'static str]),
    FileOrFolder(&'static [&'static str]),
}

impl Pick {
    fn extensions(self) -> &'static [&'static str] {
        match self {
            Pick::Folder => &[],
            Pick::File(x) | Pick::FileOrFolder(x) => x,
        }
    }

    fn folders_pickable(self) -> bool {
        !matches!(self, Pick::File(_))
    }

pub struct Entry {
    pub name: String,
    pub is_dir: bool,
}

pub enum BrowserOutcome {
    Continue,
    Chosen(PathBuf),
    Cancel,
}

fn wanted(name: &str, exts: &[&str]) -> bool {
    Path::new(name).extension().and_then(|e| e.to_str()).is_some_and(|e| exts.iter().any(|x| x.eq_ignore_ascii_case(e)))
}

// What `pick` can show in `dir`: folders first, then matching files, each sorted without regard to case.
pub fn list_dir(dir: &Path, pick: Pick, hidden: bool) -> Result<Vec<Entry>, String> {
    let read = std::fs::read_dir(dir).map_err(|e| format!("Can't read {}: {}", dir.display(), e))?;
    let mut entries: Vec<Entry> = read
        .filter_map(Result::ok)
        .filter_map(|e| {
            let name = e.file_name().to_string_lossy().into_owned();
            if !hidden && name.starts_with('.') {
                return None;
            }
            let is_dir = e.path().is_dir(); // follows symlinks
            let show = match pick {
                Pick::Folder => is_dir,
                Pick::File(x) | Pick::FileOrFolder(x) => is_dir || wanted(&name, x),
            };
            show.then_some(Entry { name, is_dir })
        })
        .collect();
    entries.sort_by(|a, b| b.is_dir.cmp(&a.is_dir).then_with(|| a.name.to_lowercase().cmp(&b.name.to_lowercase())));
    Ok(entries)
}

fn home_or_cwd() -> PathBuf {
    std::env::var_os("HOME")
        .or_else(|| std::env::var_os("USERPROFILE"))
        .map(PathBuf::from)
        .filter(|p| p.is_dir())
        .or_else(|| std::env::current_dir().ok())
        .unwrap_or_else(|| PathBuf::from("."))
}

pub struct Browser {
    title: String,
    dir: PathBuf,
    pick: Pick,
    hidden: bool,
    all: Vec<Entry>,
    filter: String,
    filtering: bool,
    typed: Option<Input>,
    selected: usize,
    state: ListState,
    pub(super) error: String,
}

impl Browser {
    // Opens at `start` if that is a folder, at the folder holding it (with it selected) if it
    // is a file, else at the home folder.
    pub fn new(title: &str, start: &str, pick: Pick) -> Browser {
        let given = user_path(start);
        let (dir, name) = if start.trim().is_empty() {
            (home_or_cwd(), None)
        } else if given.is_dir() {
            (given, None)
        } else if let Some(parent) = given.parent().filter(|p| p.is_dir()) {
            (parent.to_path_buf(), given.file_name().map(|n| n.to_string_lossy().into_owned()))
        } else {
            (home_or_cwd(), None)
        };
        let mut b = Browser {
            title: title.to_string(),
            dir,
            pick,
            hidden: false,
            all: Vec::new(),
            filter: String::new(),
            filtering: false,
            typed: None,
            selected: 0,
            state: ListState::default(),
            error: String::new(),
        };
        b.reload(name.as_deref());
        b
    }

    pub fn dir(&self) -> &Path {
        &self.dir
    }

    pub fn selected_name(&self) -> Option<String> {
        self.visible().get(self.selected).map(|e| e.name.clone())
    }

    fn visible(&self) -> Vec<&Entry> {
        let needle = self.filter.to_lowercase();
        self.all.iter().filter(|e| needle.is_empty() || e.name.to_lowercase().contains(&needle)).collect()
    }

    // Re-reads the folder, clears the filter and selects `name` if it is listed.
    fn reload(&mut self, name: Option<&str>) {
        match list_dir(&self.dir, self.pick, self.hidden) {
            Ok(all) => {
                self.all = all;
                self.error.clear();
            }
            Err(e) => {
                self.all.clear();
                self.error = e;
            }
        }
        self.filter.clear();
        self.filtering = false;
        self.selected = name.and_then(|n| self.all.iter().position(|e| e.name == n)).unwrap_or(0);
    }

    fn enter(&mut self, dir: PathBuf) {
        self.dir = dir;
        self.reload(None);
    }

    fn up(&mut self) {
        if let Some(parent) = self.dir.parent().map(Path::to_path_buf) {
            let left = self.dir.file_name().map(|n| n.to_string_lossy().into_owned());
            self.dir = parent;
            self.reload(left.as_deref());
        }
    }

    pub fn handle_key(&mut self, key: KeyEvent) -> BrowserOutcome {
        if self.typed.is_some() {
            return self.key_typed(key);
        }
        if self.filtering {
            self.key_filter(key);
            return BrowserOutcome::Continue;
        }
        let last = self.visible().len().saturating_sub(1);
        match key.code {
            KeyCode::Esc => {
                if self.filter.is_empty() {
                    return BrowserOutcome::Cancel;
                }
                self.filter.clear();
                self.selected = 0;
            }
            KeyCode::Up | KeyCode::Char('k') => self.selected = self.selected.saturating_sub(1),
            KeyCode::Down | KeyCode::Char('j') => self.selected = (self.selected + 1).min(last),
            KeyCode::PageUp => self.selected = self.selected.saturating_sub(10),
            KeyCode::PageDown => self.selected = (self.selected + 10).min(last),
            KeyCode::Home => self.selected = 0,
            KeyCode::End => self.selected = last,
            KeyCode::Enter => {
                if let Some(e) = self.visible().get(self.selected).map(|e| (*e).clone()) {
                    let path = self.dir.join(&e.name);
                    if e.is_dir {
                        self.enter(path);
                    } else {
                        return BrowserOutcome::Chosen(path);
                    }
                }
            }
            KeyCode::Backspace | KeyCode::Left | KeyCode::Char('h') => self.up(),
            KeyCode::Char('~') => self.enter(home_or_cwd()),
            KeyCode::Char('/') => self.filtering = true,
            KeyCode::Char('.') => {
                let keep = self.selected_name();
                self.hidden = !self.hidden;
                self.reload(keep.as_deref());
            }
            KeyCode::Tab => {
                let start = format!("{}{}", self.dir.display(), std::path::MAIN_SEPARATOR);
                self.typed = Some(Input::new(&start));
                self.error.clear();
            }
            KeyCode::Char(' ') if self.pick.folders_pickable() => return BrowserOutcome::Chosen(self.dir.clone()),
            _ => {}
        }
        BrowserOutcome::Continue
    }

    fn key_filter(&mut self, key: KeyEvent) {
        match key.code {
            KeyCode::Esc => {
                self.filter.clear();
                self.filtering = false;
            }
            KeyCode::Enter => self.filtering = false,
            KeyCode::Backspace => {
                if self.filter.pop().is_none() {
                    self.filtering = false;
                }
            }
            KeyCode::Char(c) => self.filter.push(c),
            _ => {}
        }
        self.selected = 0;
    }

    fn key_typed(&mut self, key: KeyEvent) -> BrowserOutcome {
        let Some(input) = self.typed.as_mut() else { return BrowserOutcome::Continue };
        match key.code {
            KeyCode::Esc => self.typed = None,
            KeyCode::Enter => {
                let mut path = user_path(&input.value());
                if path.is_relative() {
                    path = self.dir.join(path);
                }
                if path.is_dir() {
                    self.typed = None;
                    if self.pick.folders_pickable() {
                        return BrowserOutcome::Chosen(path);
                    }
                    self.enter(path);
                } else if path.is_file() && (self.pick.extensions().is_empty() || wanted(&path.to_string_lossy(), self.pick.extensions())) {
                    return BrowserOutcome::Chosen(path);
                } else {
                    self.error = format!("'{}' was not found (or is not a type you can pick here).", path.display());
                }
            }
            _ => {
                input.handle_key(key);
            }
        }
        BrowserOutcome::Continue
    }

    pub fn render(&mut self, f: &mut Frame, area: Rect) {
        let rect = super::editor::centered(area, (area.width * 9 / 10).max(30), area.height.saturating_sub(2).max(5));
        f.render_widget(Clear, rect);
        let block = Block::bordered().title(format!(" {} ", self.title));
        let inner = block.inner(rect);
        f.render_widget(block, rect);
        let [path_row, list_row, hint_row] = Layout::vertical([Constraint::Length(1), Constraint::Min(1), Constraint::Length(1)]).areas(inner);

        let mut cursor = None;
        let path_line = match &self.typed {
            Some(input) => {
                let (text, col) = input.view(path_row.width.saturating_sub(7) as usize);
                cursor = Some((path_row.x + 6 + col as u16, path_row.y));
                format!("Path: {}", text)
            }
            None if self.filtering || !self.filter.is_empty() => format!("Filter: {}  ({})", self.filter, self.dir.display()),
            None => self.dir.display().to_string(),
        };
        f.render_widget(Paragraph::new(path_line), path_row);

        let items: Vec<ListItem> = self
            .visible()
            .iter()
            .map(|e| if e.is_dir { ListItem::new(format!("{}/", e.name)).style(Style::new().add_modifier(Modifier::BOLD)) } else { ListItem::new(e.name.clone()) })
            .collect();
        if items.is_empty() {
            f.render_widget(Paragraph::new("(nothing here)"), list_row);
        } else {
            self.state.select(Some(self.selected));
            let list = List::new(items).highlight_style(Style::new().add_modifier(Modifier::REVERSED)).highlight_symbol(">");
            f.render_stateful_widget(list, list_row, &mut self.state);
        }

        let hint = match self.pick {
            Pick::Folder => "Enter open  Space choose this folder  Backspace up  / filter  . hidden  Tab type path  Esc cancel",
            Pick::File(_) => "Enter open or pick  Backspace up  / filter  . hidden  Tab type path  Esc cancel",
            Pick::FileOrFolder(_) => "Enter open or pick  Space choose this folder  Backspace up  / filter  . hidden  Tab type path  Esc cancel",
        };
        let line = if self.error.is_empty() { Paragraph::new(hint) } else { Paragraph::new(self.error.clone()).style(Style::new().fg(Color::Yellow)) };
        f.render_widget(line, hint_row);
        if let Some(pos) = cursor {
            f.set_cursor_position(pos);
        }
    }
}

// Long work (analysis, splitting) on a worker thread, reporting through the same
// `pipeline::Event`s the CLI and GUI use, so the screen never blocks.
use audiobook_splitter_rust::pipeline::Event;
use std::sync::mpsc::{self, Receiver};
use std::thread;

pub enum Msg<T> {
    Event(Event),
    Done(Result<T, String>),
}

pub struct Job<T> {
    rx: Receiver<Msg<T>>,
}

impl<T: Send + 'static> Job<T> {
    pub fn spawn(work: impl FnOnce(&mut dyn FnMut(Event)) -> Result<T, String> + Send + 'static) -> Job<T> {
        let (tx, rx) = mpsc::channel();
        thread::spawn(move || {
            let result = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| {
                work(&mut |e| {
                    let _ = tx.send(Msg::Event(e));
                })
            }))
            .unwrap_or_else(|_| Err("The background job crashed.".to_string()));
            let _ = tx.send(Msg::Done(result));
        });
        Job { rx }
    }
}

impl<T> Job<T> {
    pub fn from_receiver(rx: Receiver<Msg<T>>) -> Job<T> {
        Job { rx }
    }

    pub fn try_next(&self) -> Option<Msg<T>> {
        self.rx.try_recv().ok()
    }
}

// The screen shown while a job runs: the current stage as a gauge, and the log below it.
use crate::cli::time::clock;
use audiobook_splitter_rust::pipeline::Event;
use ratatui::layout::{Constraint, Layout, Rect};
use ratatui::text::Line;
use ratatui::widgets::{Block, Gauge, Paragraph};
use ratatui::Frame;
use std::time::Instant;

const KEEP_LINES: usize = 500;

pub struct Progress {
    title: String,
    stage: String,
    done: usize,
    total: usize,
    pub(super) log: Vec<String>,
    started: Instant,
}

impl Progress {
    pub fn new(title: &str) -> Progress {
        Progress { title: title.to_string(), stage: String::new(), done: 0, total: 0, log: Vec::new(), started: Instant::now() }
    }

    pub fn apply(&mut self, event: Event) {
        match event {
            Event::Stage { name, total } => {
                self.stage = name;
                self.total = total;
                self.done = 0;
            }
            Event::Tick(done) => self.done = done,
            Event::Log(line) => {
                self.log.push(line);
                if self.log.len() > KEEP_LINES {
                    self.log.drain(..self.log.len() - KEEP_LINES);
                }
            }
        }
    }

    pub fn render(&self, f: &mut Frame, area: Rect) {
        let block = Block::bordered().title(format!(" {} ", self.title));
        let inner = block.inner(area);
        f.render_widget(block, area);
        let [gauge_row, log_area] = Layout::vertical([Constraint::Length(1), Constraint::Min(0)]).areas(inner);
        let ratio = if self.total == 0 { 0.0 } else { (self.done as f64 / self.total as f64).clamp(0.0, 1.0) };
        let label = format!("{}  {}/{}  {}", if self.stage.is_empty() { "Starting" } else { &self.stage }, self.done, self.total, clock(self.started.elapsed().as_secs_f64()));
        f.render_widget(Gauge::default().ratio(ratio).label(label), gauge_row);
        let rows = log_area.height as usize;
        let tail: Vec<Line> = self.log.iter().skip(self.log.len().saturating_sub(rows)).map(|l| Line::raw(l.as_str())).collect();
        f.render_widget(Paragraph::new(tail), log_area);
    }
}

// The Setup screen: where the book is, where the output goes, and the analysis options.
use super::browser::{Browser, BrowserOutcome, Pick};
use super::input::Input;
use audiobook_splitter_rust::plan::Settings;
use audiobook_splitter_rust::{collect_inputs, user_path, AUDIO_EXTENSIONS};
use ratatui::crossterm::event::{KeyCode, KeyEvent, KeyModifiers};
use ratatui::layout::Rect;
use ratatui::style::{Color, Modifier, Style};
use ratatui::text::{Line, Span};
use ratatui::widgets::{Block, Paragraph};
use ratatui::Frame;
use std::path::PathBuf;

const LABELS: [&str; 7] = ["Audio file or folder", "EPUB (optional)", "Output folder", "Minimum silence (s)", "Noise level (dB)", "Match threshold (0-1)", "Use cache"];
const ROWS: usize = LABELS.len();
const CACHE_ROW: usize = 6;

#[derive(Debug)]
pub struct AnalyzeRequest {
    pub inputs: Vec<PathBuf>,
    pub epub: Option<PathBuf>,
    pub out: PathBuf,
    pub settings: Settings,
    pub use_cache: bool,
}

pub enum SetupOutcome {
    Continue,
    Start(AnalyzeRequest),
    Quit,
}

pub struct Setup {
    fields: Vec<Input>, // rows 0..=5
    cache: bool,
    focus: usize,
    browser: Option<(usize, Browser)>,
    feedback: [String; 3], // live notes beside the three path rows
    pub error: String,
}

// A short note on what a path row's text points at.
fn describe(row: usize, text: &str) -> String {
    let t = text.trim();
    if t.is_empty() {
        return String::new();
    }
    let path = user_path(t);
    match row {
        0 => match collect_inputs(&path) {
            Ok(files) if files.is_empty() => "no audio files".into(),
            Ok(files) => format!("{} audio file{}", files.len(), if files.len() == 1 { "" } else { "s" }),
            Err(_) => "not found".into(),
        },
        1 => if path.is_file() { "found".into() } else { "not found".into() },
        _ => {
            if path.is_dir() {
                "existing folder".into()
            } else if path.exists() {
                "not a folder".into()
            } else {
                "will be created".into()
            }
        }
    }
}

impl Setup {
    pub fn new(prefill: Option<&str>) -> Setup {
        let d = Settings::default();
        let mut s = Setup {
            fields: [prefill.unwrap_or(""), "", "", &d.min_silence.to_string(), &d.noise_db.to_string(), &d.threshold.to_string()].iter().map(|v| Input::new(v)).collect(),
            cache: true,
            focus: 0,
            browser: None,
            feedback: Default::default(),
            error: String::new(),
        };
        s.refresh(0);
        s
    }

    fn refresh(&mut self, row: usize) {
        if row < 3 {
            self.feedback[row] = describe(row, &self.fields[row].value());
        }
    }

    // Checks everything cheap before any slow work starts, like the CLI and the GUI do.
    pub fn request(&self) -> Result<AnalyzeRequest, String> {
        let input = self.fields[0].value();
        if input.trim().is_empty() {
            return Err("Choose an audio file or folder.".into());
        }
        let path = user_path(&input);
        let inputs = collect_inputs(&path)?;
        if inputs.is_empty() {
            return Err(format!("No supported audio files found in '{}'.", path.display()));
        }
        let epub_text = self.fields[1].value();
        let epub = Some(user_path(&epub_text)).filter(|_| !epub_text.trim().is_empty());
        if let Some(e) = &epub {
            if !e.is_file() {
                return Err(format!("The EPUB '{}' was not found.", e.display()));
            }
        }
        let out_text = self.fields[2].value();
        if out_text.trim().is_empty() {
            return Err("Choose an output folder.".into());
        }
        let out = user_path(&out_text);
        if out.exists() && !out.is_dir() {
            return Err(format!("'{}' is not a folder.", out.display()));
        }
        let number = |row: usize, name: &str| self.fields[row].value().trim().parse::<f64>().map_err(|_| format!("{} must be a number.", name));
        let settings = Settings { min_silence: number(3, "Minimum silence")?, noise_db: number(4, "Noise level")?, threshold: number(5, "Match threshold")? };
        settings.validate()?;
        Ok(AnalyzeRequest { inputs, epub, out, settings, use_cache: self.cache })
    }

    pub fn handle_key(&mut self, key: KeyEvent) -> SetupOutcome {
        if let Some((row, mut browser)) = self.browser.take() {
            match browser.handle_key(key) {
                BrowserOutcome::Continue => self.browser = Some((row, browser)),
                BrowserOutcome::Cancel => {}
                BrowserOutcome::Chosen(path) => {
                    self.fields[row] = Input::new(&path.display().to_string());
                    self.refresh(row);
                }
            }
            return SetupOutcome::Continue;
        }
        self.error.clear();
        let ctrl = key.modifiers.contains(KeyModifiers::CONTROL);
        match key.code {
            KeyCode::Esc => return SetupOutcome::Quit,
            KeyCode::Char('c') if ctrl => return SetupOutcome::Quit,
            KeyCode::Char('a') if ctrl => match self.request() {
                Ok(req) => return SetupOutcome::Start(req),
                Err(e) => self.error = e,
            },
            KeyCode::Tab | KeyCode::Down => self.focus = (self.focus + 1) % ROWS,
            KeyCode::BackTab | KeyCode::Up => self.focus = (self.focus + ROWS - 1) % ROWS,
            KeyCode::Enter if self.focus < 3 => {
                let (title, pick) = match self.focus {
                    0 => ("Choose the audio file or folder", Pick::FileOrFolder(&AUDIO_EXTENSIONS)),
                    1 => ("Choose the EPUB", Pick::File(&["epub"])),
                    _ => ("Choose the output folder", Pick::Folder),
                };
                self.browser = Some((self.focus, Browser::new(title, &self.fields[self.focus].value(), pick)));
            }
            KeyCode::Char(' ') | KeyCode::Left | KeyCode::Right | KeyCode::Enter if self.focus == CACHE_ROW => self.cache = !self.cache,
            _ if self.focus < CACHE_ROW => {
                if self.fields[self.focus].handle_key(key) {
                    self.refresh(self.focus);
                }
            }
            _ => {}
        }
        SetupOutcome::Continue
    }

    pub fn render(&mut self, f: &mut Frame, area: Rect) {
        let block = Block::bordered().title(" Setup ");
        let inner = block.inner(area);
        f.render_widget(block, area);
        let label_w = 24u16;
        let note_w = 18u16;
        let field_w = inner.width.saturating_sub(label_w + note_w + 2).max(8) as usize;
        let mut lines = Vec::new();
        let mut cursor = None;
        for row in 0..ROWS {
            let hot = self.focus == row;
            let label_style = if hot { Style::new().add_modifier(Modifier::BOLD | Modifier::REVERSED) } else { Style::new().add_modifier(Modifier::BOLD) };
            let label = Span::styled(format!("{:<w$}", LABELS[row], w = label_w as usize), label_style);
            if row == CACHE_ROW {
                lines.push(Line::from(vec![label, Span::raw(if self.cache { "[x] on" } else { "[ ] off" })]));
            } else {
                let (text, col) = self.fields[row].view(field_w);
                let note = self.feedback.get(row).cloned().unwrap_or_default();
                lines.push(Line::from(vec![label, Span::raw(format!("{:<w$}", text, w = field_w)), Span::styled(format!("  {}", note), Style::new().fg(Color::Cyan))]));
                if hot {
                    cursor = Some((inner.x + label_w + col as u16, inner.y + row as u16));
                }
            }
        }
        lines.push(Line::raw(""));
        lines.push(Line::styled(self.error.clone(), Style::new().fg(Color::Yellow)));
        lines.push(Line::raw("Tab next   Enter browse (path rows)   Space toggle   Ctrl-A analyze   Esc quit"));
        f.render_widget(Paragraph::new(lines), inner);
        match &mut self.browser {
            Some((_, browser)) => browser.render(f, area),
            None => {
                if let Some(pos) = cursor {
                    f.set_cursor_position(pos);
                }
            }
        }
    }
}

    pub path: Option<PathBuf>,
}

struct DoneInfo {
    written: usize,
    failed: usize,
    out: PathBuf,
    plan_path: Option<PathBuf>,
    error: Option<String>,
}

enum Screen {
    Setup,
    Analyzing { progress: Progress, job: Job<Plan> },
    Editor(Box<Editor>),
    PickOutput { editor: Box<Editor>, browser: Browser },
    Splitting { progress: Progress, job: Job<SplitReport> },
    Done(DoneInfo),
}

enum Finished {
    Analysis(Result<Plan, String>),
    Split(Result<SplitReport, String>),
}

// The whole terminal app: one screen at a time, the Setup form kept across screens so `b`
// (back) finds what the user typed.
pub struct App {
    screen: Screen,
    setup: Setup,
    out: Option<PathBuf>,
    plan_path: Option<PathBuf>,
    confirm_quit: bool,
    quit: bool,
}

fn is_plan_path(path: &Path) -> bool {
    path.extension().is_some_and(|e| e.eq_ignore_ascii_case("json"))
}

// Everything a running job has sent so far; the job's result if it has finished.
fn drain<T>(job: &Job<T>, progress: &mut Progress) -> Option<Result<T, String>> {
    while let Some(msg) = job.try_next() {
        match msg {
            Msg::Event(e) => progress.apply(e),
            Msg::Done(r) => return Some(r),
        }
    }
    None
}

impl App {
    pub fn new(arg: Option<&Path>) -> Result<App, String> {
        match arg {
            Some(path) if is_plan_path(path) => Ok(App::with_plan(open_plan(path)?, Some(path.to_path_buf()))),
            other => Ok(App {
                screen: Screen::Setup,
                setup: Setup::new(other.map(|p| p.display().to_string()).as_deref()),
                out: None,
                plan_path: None,
                confirm_quit: false,
                quit: false,
            }),
        }
    }

    // An app that starts in the editor on an existing plan.
    pub fn with_plan(plan: Plan, plan_path: Option<PathBuf>) -> App {
        let mut editor = Editor::new(plan);
        editor.allow_back = true;
        App { screen: Screen::Editor(Box::new(editor)), setup: Setup::new(None), out: None, plan_path, confirm_quit: false, quit: false }
    }

    pub fn is_over(&self) -> bool {
        self.quit
    }

    // Fails fast (bad EPUB, missing tools) before any slow work starts, then runs the analysis
    // on a worker thread and shows its progress.
    fn start_analysis(&mut self, req: AnalyzeRequest) -> Result<(), String> {
        check_tools()?;
        let (epub, meta) = match &req.epub {
            Some(path) => {
                let (epub, info) = open_epub(path)?;
                (Some(epub), default_metadata(Some(info)))
            }
            None => (None, default_metadata(None)),
        };
        let cache = open_cache(!req.use_cache);
        let AnalyzeRequest { inputs, epub: epub_path, out, settings, .. } = req;
        self.plan_path = Some(out.join("plan.json"));
        self.out = Some(out);
        let job = Job::spawn(move |emit| {
            let analysis = analyze(&inputs, &settings, epub.as_ref(), &cache, emit)?;
            for (i, why) in &analysis.errors {
                emit(pipeline::Event::Log(format!("Skipped {}: {}", file_name(&inputs[*i]), why)));
            }
            if analysis.files.is_empty() {
                return Err("None of the audio files could be analyzed.".to_string());
            }
            Ok(Plan::new(analysis.files, settings, epub_path, analysis.findings, meta))
        });
        self.screen = Screen::Analyzing { progress: Progress::new("Analyzing"), job };
        Ok(())
    }

    // Validates the split before anything is written, saves the plan, then writes the files on a worker thread.
    fn start_split(&mut self, mut editor: Box<Editor>, out: PathBuf) {
        let plan = editor.plan.clone();
        let prepared = prepare_split(&plan.files, &plan.findings.to_breaks(), &plan.metadata)
            .and_then(|p| std::fs::create_dir_all(&out).map(|_| p).map_err(|e| format!("Failed to create '{}': {}", out.display(), e)));
        let (segments, names) = match prepared {
            Ok(p) => p,
            Err(e) => {
                editor.set_status(e);
                self.screen = Screen::Editor(editor);
                return;
            }
        };
        if let Some(path) = &self.plan_path {
            if let Err(e) = plan.save(path) {
                editor.set_status(format!("Couldn't save the plan: {}", e));
            }
        }
        self.out = Some(out.clone());
        let (files, cover) = (plan.files.clone(), plan.metadata.cover.clone());
        let job = Job::spawn(move |emit| Ok(write_tracks(&segments, &names, &out, &files, &cover, emit)));
        self.screen = Screen::Splitting { progress: Progress::new("Splitting"), job };
    }

    // Moves finished jobs on to the next screen. Called every frame.
    pub fn tick(&mut self) {
        let finished = match &mut self.screen {
            Screen::Analyzing { progress, job } => drain(job, progress).map(Finished::Analysis),
            Screen::Splitting { progress, job } => drain(job, progress).map(Finished::Split),
            _ => None,
        };
        match finished {
            Some(Finished::Analysis(Ok(plan))) => {
                let mut notice = None;
                if let Some(path) = &self.plan_path {
                    let saved = path.parent().map_or(Ok(()), std::fs::create_dir_all).map_err(|e| e.to_string()).and_then(|_| plan.save(path));
                    if let Err(e) = saved {
                        notice = Some(format!("Couldn't save the plan: {}", e));
                    }
                }
                let mut editor = Editor::new(plan);
                editor.allow_back = true;
                if let Some(n) = notice {
                    editor.set_status(n);
                }
                self.screen = Screen::Editor(Box::new(editor));
            }
            Some(Finished::Analysis(Err(e))) => {
                self.setup.error = e;
                self.screen = Screen::Setup;
            }
            Some(Finished::Split(result)) => {
                let out = self.out.clone().unwrap_or_default();
                let info = match result {
                    Ok(report) => DoneInfo { written: report.written.len(), failed: report.failed, out, plan_path: self.plan_path.clone(), error: None },
                    Err(e) => DoneInfo { written: 0, failed: 0, out, plan_path: self.plan_path.clone(), error: Some(e) },
                };
                self.screen = Screen::Done(info);
            }
            None => {}
        }
    }

    pub fn handle_key(&mut self, key: KeyEvent) {
        if self.confirm_quit {
            self.confirm_quit = false;
            if key.code == KeyCode::Char('y') {
                self.quit = true;
            }
            return;
        }
        let ctrl_c = key.code == KeyCode::Char('c') && key.modifiers.contains(KeyModifiers::CONTROL);
        match std::mem::replace(&mut self.screen, Screen::Setup) {
            Screen::Setup => match self.setup.handle_key(key) {
                SetupOutcome::Continue => {}
                SetupOutcome::Quit => self.quit = true,
                SetupOutcome::Start(req) => {
                    if let Err(e) = self.start_analysis(req) {
                        self.setup.error = e;
                    }
                }
            },
            screen @ (Screen::Analyzing { .. } | Screen::Splitting { .. }) => {
                self.screen = screen;
                if ctrl_c || key.code == KeyCode::Char('q') {
                    self.confirm_quit = true;
                }
            }
            Screen::Editor(mut editor) => match editor.handle_key(key) {
                Outcome::Continue => self.screen = Screen::Editor(editor),
                Outcome::Discard => self.quit = true,
                Outcome::Back => self.screen = Screen::Setup,
                Outcome::Save => match self.out.clone() {
                    Some(out) => self.start_split(editor, out),
                    None => {
                        let browser = Browser::new("Choose the output folder", "", Pick::Folder);
                        self.screen = Screen::PickOutput { editor, browser };
                    }
                },
            },
            Screen::PickOutput { editor, mut browser } => match browser.handle_key(key) {
                BrowserOutcome::Continue => self.screen = Screen::PickOutput { editor, browser },
                BrowserOutcome::Cancel => self.screen = Screen::Editor(editor),
                BrowserOutcome::Chosen(out) => self.start_split(editor, out),
            },
            Screen::Done(info) => {
                if key.code == KeyCode::Char('n') {
                    self.screen = Screen::Setup;
                } else if ctrl_c || matches!(key.code, KeyCode::Char('q') | KeyCode::Enter | KeyCode::Esc) {
                    self.quit = true;
                } else {
                    self.screen = Screen::Done(info);
                }
            }
        }
    }

    pub fn render(&mut self, f: &mut Frame) {
        let area = f.area();
        match &mut self.screen {
            Screen::Setup => self.setup.render(f, area),
            Screen::Analyzing { progress, .. } | Screen::Splitting { progress, .. } => progress.render(f, area),
            Screen::Editor(editor) => editor.render(f),
            Screen::PickOutput { editor, browser } => {
                editor.render(f);
                browser.render(f, area);
            }
            Screen::Done(info) => render_done(f, area, info),
        }
        if self.confirm_quit {
            let rect = editor::centered(area, 60, 3);
            f.render_widget(Clear, rect);
            f.render_widget(Paragraph::new("A job is running. Quit anyway?   y quit    any other key: keep going").block(Block::bordered().title(" Quit ")), rect);
        }
    }
}

fn render_done(f: &mut Frame, area: Rect, info: &DoneInfo) {
    let mut lines = Vec::new();
    match &info.error {
        Some(e) => lines.push(Line::raw(format!("The split failed: {}", e))),
        None => {
            lines.push(Line::raw(format!("Wrote {} file(s) to {}.", info.written, info.out.display())));
            if info.failed > 0 {
                lines.push(Line::raw(format!("{} file(s) could not be written; see the log lines above on the last screen or run `split` on the plan.", info.failed)));
            }
        }
    }
    if let Some(p) = &info.plan_path {
        lines.push(Line::raw(format!("The plan is saved at {}.", p.display())));
    }
    lines.push(Line::raw(""));
    lines.push(Line::raw("n  another book    q or Enter  quit"));
    f.render_widget(Paragraph::new(lines).block(Block::bordered().title(" Done ")), area);
}

// `tui`: the full-screen app, from choosing the book to splitting it.
pub fn run(args: Args) -> Result<(), String> {
    if !terminal::suitable(false) {
        return Err("`tui` needs an interactive terminal at least 60 columns by 15 rows with TERM set. Use `run`, or `analyze`, `edit` and `split` step by step, instead.".into());
    }
    check_tools()?;
    let mut app = App::new(args.path.as_deref().map(|p| user_path(&p.to_string_lossy())).as_deref())?;
    let mut guard = TerminalGuard::new()?;
    while !app.is_over() {
        guard.terminal.draw(|f| app.render(f)).map_err(|e| e.to_string())?;
        if event::poll(Duration::from_millis(100)).map_err(|e| e.to_string())? {
            if let Event::Key(key) = event::read().map_err(|e| e.to_string())? {
                if key.kind == KeyEventKind::Press {
                    app.handle_key(key);
                }
            }
        }
        app.tick();
    }
    Ok(())
}

// A help popup for the screens that have no key table of their own.
use ratatui::layout::Rect;
use ratatui::style::{Modifier, Style};
use ratatui::text::{Line, Span};
use ratatui::widgets::{Block, Clear, Paragraph};
use ratatui::Frame;

pub const SETUP_KEYS: &[(&str, &str)] = &[
    ("Tab, Shift-Tab, Up, Down", "move between the fields"),
    ("Enter", "browse for a path (on the first three rows)"),
    ("Space, Left, Right", "turn the cache on or off"),
    ("Ctrl-U", "clear the field"),
    ("Ctrl-A", "start the analysis"),
    ("Esc, Ctrl-c", "quit"),
    ("F1", "this help"),
];

pub const PROGRESS_KEYS: &[(&str, &str)] = &[
    ("q, Ctrl-c", "quit (asks first; the job cannot be cancelled)"),
    ("?", "this help"),
];

pub const DONE_KEYS: &[(&str, &str)] = &[
    ("n", "another book (back to Setup)"),
    ("q, Enter, Esc", "quit"),
    ("?", "this help"),
];

pub fn render_help(f: &mut Frame, area: Rect, title: &str, keys: &[(&str, &str)]) {
    let rect = super::editor::centered(area, 70, keys.len() as u16 + 2);
    let lines: Vec<Line> = keys
        .iter()
        .map(|(k, d)| Line::from(vec![Span::styled(format!("{:<26}", k), Style::new().add_modifier(Modifier::BOLD)), Span::raw(*d)]))
        .collect();
    f.render_widget(Clear, rect);
    f.render_widget(Paragraph::new(lines).block(Block::bordered().title(format!(" {} (any key closes) ", title))), rect);
}
```
